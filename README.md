# 🏋️‍♂️ Fit-Log

## 📝 Description
Fit-Log is a modern and responsive tracking web application. This application helps users manage their daily exercise routine. Users can track their total workout duration and calorie burn in real-time.

---

## ✨ Features
* **Today’s Plan:** Add lifts to your daily routine and monitor aggregate stats.
* **Saved:** Save your favorite workouts in a dedicated tab for quick access.
* **Live Navbar Badges:** Real-time counts for both your active Plan and Saved workouts globally across the app.
* **Sorting:** Dynamically sort exercises by Duration, Calories Burned, or Rating.
* **Responsive Design:** Clean, dark-themed fitness interface optimized for all devices.
* **Context API

---

## ⚙️ Technologies Used
* **Framework:** Next.js (React Context API, Rendering)
* **Language:** TypeScript
* **Styling & UI:** Tailwind CSS & DaisyUI
* **Icons:** React Icons
